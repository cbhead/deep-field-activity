Privacy Policy

Deep Field · Effective 30 August 2026

Deep Field is a hobby tower-defense game. It has no accounts, no adverts, no analytics, no cookies and no third-party trackers, and nothing it collects is ever sold or shared for advertising. This policy describes the small amount of data it does handle, and is written to be checkable against the source code at github.com/cbhead/deep-field-activity.

Stored on your own device

Single-player progress and preferences never leave your browser. They live in localStorage and are readable only by this game, on this device:

KeyWhat it holds
td-campaignCampaign progress: grades, lives remaining, times, waves reached
race-nameThe display name you last used in Race mode
race-level, race-diffYour last sector and difficulty choice
race-seriesWin/loss tally against opponents you have raced, by name
deep-field-audioVolume and mute settings
discord-webhookA Discord webhook URL, only if you paste one in

Clearing your browser's site data for this origin erases all of it. The game's settings screen also has a Reset progress button.

Sent to the game server, during a race only

Race mode relays two players through a small server. While a race is running it holds, in memory only:

  • the display name you typed or that Discord provided;
  • a temporary player id and room code;
  • your progress numbers — wave, lives remaining and elapsed time.

There is no database and nothing is written to disk. A room and everything in it is discarded about a minute after the last player leaves, and everything is lost when the server stops — which, since it is usually run from a laptop for a session, is often.

The server prints a log line to its own terminal when a player joins, readies, finishes or disconnects. Those lines include display names and the connecting IP address. They are not stored in a file, sent anywhere, or retained after the terminal is closed, but the person running the server can see them.

Discord

When played as a Discord Activity, the game asks Discord for the identify scope and nothing else. That returns your Discord user id, username and display name. The display name is used to label you in a race; the access token is used once to complete the sign-in and is not stored. No message, server, friend or email data is requested, and none is accessible to the game.

Discord itself handles the connection and applies its own privacy policy.

Match reports, if you turn them on

Race mode can post a summary to a Discord channel through a webhook you paste in yourself. It is off unless configured. A report contains both players' display names, waves reached, lives remaining, times, the sector and the board seed. Sending it publishes that to whoever can read the channel. Removing the webhook from the settings field stops it.

Children

This game is not directed at children. Discord requires its users to be at least 13, or older where local law says so.

Your data

There is no account to delete and no server-side record to request: clearing your browser storage removes everything the game keeps about you. Discord data is held by Discord, and you can revoke this application's access at any time in Discord → Settings → Authorised Apps.
