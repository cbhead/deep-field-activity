Race lobby

A facelift for ui/lobbyScreen.ts, in the deep-field language of the in-game HUD. Every state the file actually reaches is here, in the order a player meets them. Copy leans on facts the code already guarantees — one seed drives both boards, status goes over the wire at 2Hz, a dropped socket can reclaim its seat.

Two constraints kept: the room code stays a select-on-click field rather than a copy button (over Tailscale the page is plain http, so navigator.clipboard fails everywhere except localhost), and the screen carries its own styling — it lives and dies before the game exists.

How a race works
01 One seed, two boardsThe relay hands both pilots the same seed, so every wave arrives in the same order with the same jitter. Nothing about the board is luck.
02 Ahead or behind, liveWave, lives and elapsed time cross the wire twice a second. You see their standing, never their board.
03 Your seat is heldLose the connection and you can reclaim the same seat and carry on. Walk away and it's a forfeit.
