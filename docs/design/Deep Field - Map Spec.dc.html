Deep Field Map spec · sectors 04–08 · 30 Aug 2026

Five boards, and the one model change they need

Three boards today all ask the same question — where is the longest stretch of road I can afford to cover. These five ask a different one, and they get there on a single structural change: a map carries routes, plural.

The change, in one line. MapSource.waypoints: TileCoord[] becomes MapSource.routes: RouteSource[], and a creep carries which route it is walking. Everything else in this document follows from that.

1 · The route model

A route is an id and a waypoint chain. Nothing else — no per-route speed, no weighting, no priority. Those would all be reasonable and all be premature; the geometry is doing the work here, and a second knob on top of it would only hide which one mattered.

FieldTypeNotes
RouteSource.idstringUnique within the map. Authoring handle and the key a wave group names.
RouteSource.waypointsreadonly TileCoord[]Exactly today’s rules: right-angle turns, first tile an S, last tile an E.
MapSource.routesreadonly RouteSource[]At least one. A single-route map is the old shape and reads identically.
Creep.routenumberIndex, not id — the sim is on the hot path and should not be hashing strings per tick.
WaveGroup.routestring | 'split'A route id pins the group to one lane. 'split' deals it round-robin across every route, in index order.
MapDef.routes{ waypoints: Vec2[]; length: number }[]Replaces waypoints and pathLength. Each carries its own off-board lead-in entry.

Why round-robin and not random

Lane assignment must be reproducible from the seed alone, because a race replays the same wave plan on two clients and a divergence there is a desync, not a difference of opinion. Round-robin in index order needs no RNG stream at all, which is one fewer thing that can drift. It also means 'split' on a count of 12 across two lanes is always 6 and 6 — a designer can reason about it.

2 · Validation

parseMap’s cross-check is the reason the ASCII and the waypoints have not drifted, and it generalises without losing anything. Per route, unchanged: right angles only, no duplicate waypoints, never leaves the board, never crosses a non-path tile. Across routes, three new rules:

  • Every route starts on a painted S and ends on a painted E. Multiple S and E glyphs are now legal; a lone S with no route leaving it is an error, because it would draw a spawn marker nothing ever comes out of.
  • The union of all routes covers every painted path tile. Same orphaned-road check as today, computed against the union rather than the one chain.
  • Shared tiles are legal and expected. A merge is two routes covering the same tiles, so the old “each tile once” instinct has to be explicitly not-a-rule, or every board below fails to load.

Merge runway rule. The tiles between the last merge and the goal, as a fraction of the shortest route. Guarding the merge must be legal but insufficient: at or under 20% on the boards that want coverage, and stated deliberately where it is looser. Every board below records its own figure — it is the single number that decides whether a board can be solved by one cluster.

3 · The five boards

All five are 26 × 15, matching the existing three, so the viewport, the board thumbnails and the shot tooling need no changes. Lanes are drawn as value steps of the route accent — no new hues, holding the line the contact spec set. The boards below are reference thumbnails; at this size the per-lane phase offset is too small to separate on a shared trunk, so read Board Mockups at play scale for that, and the route tables here for the authoritative geometry.

4 · What this does to balance

Splitting a wave across lanes is not a difficulty increase; it is a redistribution, and it changes what the roster is worth. Worth saying plainly before the sweep says it louder:

StationEffectWhy
Lance (pierce)Down, sharplyPierce pays by file length, and a split halves every file. Braid is its floor.
Nova (splash)Roughly flatSplash wants a clump, and a lane still clumps — there are just two of them.
Arc (chain)UpChain needs proximity, not alignment, and it is the only thing that reads a merge well.
Singularity (slow)Down as a force multiplierIt no longer manufactures the condition Lance wants, because the file it bunches is half as long. This is the pair the sweep flagged, weakened by geometry rather than by a nerf.
Ramping stationsUp on Delta, down elsewhereA ramp wants one target held. Delta’s trunk gives that; Braid never does.

None of it needs a number changed. That is the argument for doing geometry before touching balance.ts again — the sweep’s marginal-contribution block should be re-run across eight boards before anything is re-tuned.

What is deliberately not in this change

  • No flying or off-road lanes. They need a seventh contact and a second movement mode, and the contact spec just closed.
  • No terrain modifiers — vantage, interference, conduit tiles. A real option, and a cleaner one to evaluate once routes have landed and the sweep has re-baselined.
  • No mid-run route mutation. Gated terrain that opens a new lane would invalidate every creep’s leg and progress mid-walk. If it is wanted, it opens build area, never road.
  • No second goal. Two goals with different life costs is a different game about triage; one goal keeps this change about coverage.
