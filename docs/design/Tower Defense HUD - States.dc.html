Deep Field HUD — state set

The agreed direction built out across every state the loop actually reaches. Board and chrome are fixed; only what the state changes is different frame to frame. Values are the real ones from balance.ts and towers.ts — 20 starting lives, $250 start, 70% sell refund, $20 wave-clear bonus, 8s intermission.

The most important feedback in the game and the one the current build only logs to the console. Three signals at once: the pulsar flares red, an edge rim pulses inward, and the lives figure counts down in place — so it's legible whether you were watching the core or the deck.
